一、产品简介

FinExtract 用于将非标准化的上市公司公告（股份质押、中标、股权变动等）自动转换为结构化数据：识别事件、提取字段、绑定原文证据、执行业务规则校验，并输出可供审查的完整记录。

系统提供两档处理方案：

迅捷 · 高效处理 以 DeepSeek 完成主提取，配合条件修复规则，速度快，适合日常批量处理。

智衡 · 专业处理 在迅捷能力之上，风险触发时自动执行跨模型独立复核（Qwen Plus），并生成公告要点摘要、关键数值汇总与风险差异审阅，适合重要公告的深度审查。

三、配置模型密钥 重点必读 · 开始分析前的必要步骤

请务必先完成本章，再开始分析。未配置密钥时，系统页面可以正常打开浏览，但无法创建任何提取任务——上传区会提示「提取核心不可用」，首页会显示金色提示横幅。整个配置约需 3–5 分钟，只需做一次，以后使用无需重复配置。

第 1 步：获取模型密钥（已有密钥可跳过）

系统使用两家模型服务商，按需获取对应的 API Key：

密钥名称用途获取地址是否必需
DEEPSEEK_API_KEY迅捷 / 智衡的主处理模型（DeepSeek）platform.deepseek.com必需
QWEN_API_KEY智衡方案的独立复核模型（Qwen Plus）阿里云百炼 bailian.console.aliyun.com推荐

DeepSeek 密钥获取方法：打开 platform.deepseek.com → 注册 / 登录 → 左侧菜单「API keys」→「创建 API key」→ 复制以 sk- 开头的密钥（只显示一次，请立即妥善保存）。调用前请在「充值」页面确认账户有余额。

Qwen Plus 密钥获取方法：打开阿里云百炼控制台 bailian.console.aliyun.com → 开通百炼服务 → 右上角「API-KEY」→「创建我的 API-KEY」→ 复制以 sk- 开头的密钥。新开通用户通常有免费调用额度。

第 2 步：打开配置目录

  1. 按键盘 Win + E 打开「文件资源管理器」；
  2. 点击窗口顶部的地址栏，粘贴下面这段路径，按回车：
    %LOCALAPPDATA%\FinExtract\config
  3. 如果提示「文件夹不存在」：先双击启动一次 FinExtract（启动时会自动创建该目录），或在 %LOCALAPPDATA%\FinExtract 下手动新建一个名为 config 的文件夹。

第 3 步：新建密钥配置文件

  1. 在 config 文件夹的空白处点击鼠标右键 →「新建」→「文本文档」；
  2. 把文件命名为 API.env（文件名其实任意——keys.txt、我的密钥.txt 均可，程序启动时会自动扫描该目录下所有文件；推荐统一用 API.env 便于管理）。
    提示：若 Windows 隐藏了扩展名，文件实际名字可能是 API.env.txt，同样可以被正常识别，不影响使用。

第 4 步：写入密钥并保存

  1. 双击刚新建的文件，用记事本打开；
  2. 复制下面两行内容粘贴进去，并把 sk-你的…密钥 替换为第 1 步获取到的真实密钥（等号两侧不要留空格，密钥不要加引号）：
DEEPSEEK_API_KEY=sk-你的DeepSeek密钥 QWEN_API_KEY=sk-你的百炼密钥
  1. 按 Ctrl + S 保存，关闭记事本。只有 DeepSeek 密钥时只写第一行即可——智衡方案仍可执行主提取与规则校验，只是独立复核环节会如实标注「未配置 / 未执行」。

第 5 步：重启程序并验证配置成功

  1. 关闭 FinExtract 的黑色启动窗口，重新双击 启动 FinExtract.bat；
  2. 程序启动时会自动对模型做真实连接验证（联网，约需几秒钟）；
  3. 配置成功的两个标志：① 首页不再显示金色「尚未配置模型密钥」提示横幅；② 进入「智能文档处理」页，方案卡片显示绿色状态「可用 · 以本次配置为准」。此时即可开始上传分析。
修改或更换密钥后必须重启程序才会生效；系统会按新密钥自动重新验证，不会沿用旧的缓存结果。

配置后仍不可用？逐项自查

检查项正确做法
变量名拼写必须严格为 DEEPSEEK_API_KEY 与 QWEN_API_KEY（全大写、下划线），不能多写字母或空格
等号格式写成 KEY=sk-xxx 一行一个；等号两侧无空格；密钥前后不要加引号
文件位置配置文件必须放在 %LOCALAPPDATA%\FinExtract\config\ 目录内，而不是程序解压目录
是否已重启每次修改密钥后，必须完全关闭启动窗口再重新启动程序
账户状态DeepSeek 账户需有余额；百炼需已开通服务且密钥未过期 / 未删除
网络连接启动验证需要联网；公司网络若有限制，请确认能访问 api.deepseek.com 与 dashscope.aliyuncs.com
隐私说明：密钥只保存在你自己电脑的 config 目录中，不随程序分发、不会上传；除调用模型服务本身外，系统不会把密钥发送给任何第三方，日志中也只显示密钥名称、绝不显示完整内容。

四、分包安装说明（如收到的是两个压缩包）

为便于传输，便携版可能拆分为 2 个压缩包分发（均不超过 100 MB）。两个包缺一不可，需要解压到同一文件夹合并后才能运行。

文件大小内容
FinExtract_v1.0_Part1_主程序.zip 约 60 MB 启动器 FinExtract.exe、启动/关闭脚本、本手册、SHA256 校验文件，以及 _internal\ 中的 Python 运行时、业务代码、Web 框架等小体量依赖
FinExtract_v1.0_Part2_AI引擎.zip 约 87 MB _internal\cv2、_internal\pymupdf、_internal\onnxruntime、_internal\rapidocr_onnxruntime —— PDF 解析与 OCR 图像识别引擎

合并安装步骤

建目录：在想要安装的位置新建一个空文件夹，例如 D:\Apps\FinExtract\（路径可含中文，建议避免特殊符号）。
解压 Part 1：右键 FinExtract_v1.0_Part1_主程序.zip →「全部解压」→ 选择刚建好的文件夹，得到 FinExtract_Windows_Portable_v1.0\ 目录。
解压 Part 2 到同一位置：右键 FinExtract_v1.0_Part2_AI引擎.zip →「全部解压」→ 选择同一个目标文件夹。Windows 提示「目标已包含名为 _internal 的文件夹」时，选择「合并 / 是」。
核对结构：进入 FinExtract_Windows_Portable_v1.0\，应能看到 FinExtract.exe、启动 FinExtract.bat 与 _internal\ 文件夹并列；_internal\ 内应同时存在 cv2、pymupdf、onnxruntime、rapidocr_onnxruntime 四个子文件夹。
启动：双击 启动 FinExtract.bat，按第三章完成密钥配置即可开始使用。
两个包缺一不可：只解压 Part 1 启动时会因缺少 cv2 / pymupdf 导致 PDF 与扫描件识别失败；只解压 Part 2 没有启动器无法运行。
必须合并到同一目录：解压时请确认 Part 2 的目标位置与 Part 1 完全一致，不要让解压软件把它套到子目录里，否则程序找不到 OCR 依赖。
校验完整性：合并完成后，可参考 Part 1 中的 SHA256.txt 校验 FinExtract.exe 的哈希值，确认两个包均未损坏。
单包版说明：如果你收到的是单一压缩包 FinExtract_Windows_Portable_v1.0.zip（约 146 MB），无需合并，直接解压即可，跳过本章进入第五章。

五、快速开始（请先完成第三章密钥配置）

解压 / 合并分包：单包版直接将 FinExtract_Windows_Portable_v1.0.zip 解压到任意文件夹；分包版请按第四章把 Part 1 与 Part 2 解压合并到同一文件夹。
配置密钥（首次使用必做）：按第三章完成模型密钥配置。这是一次性步骤，已配置过的用户可直接跳到下一步。
启动：双击 启动 FinExtract.bat。首次启动会初始化数据目录并加载组件，请等待约 10–30 秒（部分电脑首次需 1–3 分钟），浏览器将自动打开系统首页。
开始分析：在「智能文档处理」页上传公告文件，选择处理方案，即可开始提取。处理完成后在「数据审查中心」逐字段核对结果。
若浏览器没有自动打开，请手动访问启动窗口中显示的地址（默认 http://127.0.0.1:8000/）。
首次运行时，Windows SmartScreen 可能提示「已保护你的电脑」——这是未签名程序的常规提示。点击「更多信息」→「仍要运行」即可。

六、四大页面使用指南

1. 工作台

总览已处理公告数、成功率、已发布字段与待复核数量；查看处理任务分布与最近任务列表，可按处理方案筛选。

2. 智能文档处理

拖拽或点击上传公告文件（可多选），选择处理方案后提交。页面实时显示解析、事件识别、字段提取、校验修复各阶段进度；失败任务会保留原因并支持重试。

3. 数据审查中心

按任务逐字段核对提取结果：左侧为原文证据与审计信息，右侧为字段值与审核操作。智衡任务额外提供「公告要点摘要」「关键数值汇总」与「风险与异常审阅」（逐条列出复核发现的差异）。支持备注、复核与发布状态管理，并可导出 Excel / CSV / JSON。

4. 质量评估与分析

对已完成任务执行无参考可靠性诊断：结构规范率、证据关联率、规则通过率与需关注问题数量；支持导出质量报告。

七、支持的文件格式

格式说明
PDF（文字版）直接解析文字层，效果最佳
PDF（扫描件）自动调用本地 OCR 识别（纯 CPU，无需联网下载模型），耗时略长

PowerPoint（.pptx）解析文本框与表格

单文件建议不超过 50 MB；超长文档会自动分块处理。

八、数据安全与隐私

  • 本机存储：全部任务数据（数据库、上传原件、提取结果、导出文件、日志）保存在 %LOCALAPPDATA%\FinExtract\，不写入程序目录，卸载或移动程序不影响历史数据。
  • 模型调用：仅当创建处理任务时，公告文本内容会发送给你所配置的模型服务商（DeepSeek / 阿里云百炼）API 进行处理。
  • 密钥安全：API Key 仅存于本机 config 目录，绝不出现在程序压缩包内。
  • 断网行为：断网时页面与历史数据仍可正常浏览；新任务会明确提示网络异常，绝不返回虚构结果。

九、安全退出与数据保留

  • 推荐直接关闭启动窗口（或在窗口内按 Ctrl+C），系统会优雅停止服务。
  • 也可运行 关闭 FinExtract.bat 一键停止。
  • 关闭后重新启动，历史任务、字段与证据全部保留（SQLite 数据库自动保护，即使意外断电也不会损坏已提交的数据）。
  • 重复双击启动脚本不会产生第二个实例，只会再次打开浏览器进入已运行的系统。

十、常见问题

Q0：我收到的是两个压缩包，怎么用？

请按第四章「分包安装说明」把 Part 1（主程序）与 Part 2（AI 引擎）解压合并到同一文件夹。只解压其中一个会出现：缺 Part 2 时 PDF/扫描件识别失败；缺 Part 1 时没有启动器，无法运行。

Q1：双击启动后闪退？

请勿删除解压目录中的任何文件；右键 启动 FinExtract.bat → 编辑，确认路径未包含异常字符。若仍失败，运行一次 FinExtract.exe 查看具体错误文字。

Q2：提示端口被占用？

系统自动尝试 8000–8010 共 11 个端口，无需手动处理。启动窗口会显示实际使用的地址。

Q2+：双击后浏览器迟迟没有自动打开？

首次启动（或刚更新版本）时，Windows 安全扫描会让程序引导多花 1–3 分钟，属正常现象。启动窗口显示「启动于 http://...」后浏览器即会自动打开，请耐心等待，不要重复双击。

Q3：上传后提示「提取核心不可用」？

表示未检测到 DEEPSEEK_API_KEY。请按第三章「配置模型密钥」完成配置后重启。历史任务查看不受影响。

Q4：智衡方案提示复核未执行？

风险复核依赖 QWEN_API_KEY。未配置或额度不足时，系统会如实标注「未触发增强复核 / 复核未完成」，主提取结果不受影响。

Q5：扫描件识别慢或为空？

扫描件走 OCR 通道，CPU 识别每页约需数秒至数十秒。若产出为空，多为图像清晰度不足，建议提高扫描分辨率后重试。

Q6：数据占用了太多磁盘空间？

可备份后清理 %LOCALAPPDATA%\FinExtract\data\jobs\ 中不再需要的旧任务目录（数据库记录会保留，但该任务的原始文件与导出缓存会被移除）。

Q7：如何彻底卸载？

删除解压目录即可移除程序；删除 %LOCALAPPDATA%\FinExtract\ 即可移除全部本地数据。
